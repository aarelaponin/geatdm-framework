## Example input

**[your administration]:** MoEYS, Progressa's ministry of education.

**[paste it]:** The supplier's written answer, from MoEYS's acceptance file:

- Our check refuses a list that reads straight from the database and carries more than one filter.
- Our check refuses a workflow step whose screen can show the step as completed while the workflow does not move on.
- Our check refuses a model written for any release other than 9.0.7.
- Our check refuses a menu entry name used twice in the same category.

**[paste them]:** My notes, 12 November 2026, MoEYS's ICT unit:

- Check run on our model. It reported the list of PHEQA's advice awaiting the minister: two filters, the rule and the reason. Model corrected to one filter; check run again; passed.
- Supplier showed a slide on the workflow-step rule and said the check covers it. Not run: no workflow step in our model.
- Supplier changed the release in a copy of our file to 9.0.6; the check refused it on screen.
- Menu names rule: mentioned, not discussed.

**Open questions**

2. Run the menu-names rule on a copy of our model with a repeated name.
3. Who updates the rules when MoEYS's installation moves to a new release?

## Reading the output

### 1. Rows 1 and 3 are earned

Both match the notes: the check ran on MoEYS's own file, reported, and was run again. The release rule was shown on a copy of that file, which is still our model. These two rows can go into the acceptance file as evidence.

### 2. A slide was counted as a run

Row 2 is marked "Shown" on the strength of a slide. The notes say plainly that it was not run, and the prompt forbids marking a rule as shown unless the notes say so. This is the line the safeguard exists for: change it to "only stated", and ask for the check to run on a model that has a workflow step, such as PHEQA's.

### 3. Question 1 is worth keeping

The prompt did not ask where each rule comes from, but the answer matters. A rule taken from the maker's published list of known issues can be checked by anyone; a rule from the supplier's own experience can only be taken on trust.
