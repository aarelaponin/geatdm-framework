# The screens of a use case

What a person sees at each step of the story, with the source of every value on every screen. The walk-through that officials click is produced from this record, never drawn by hand.

## How to use this blank instrument

Copy this page into your own document. Fill in the answer to every line. Do not leave a line empty: write "none" where nothing applies, and where the answer is not yet known write an open question with the name of its owner and a date. Do not guess an answer to close a question. When the document is finished, give it to the person who accepts it, together with the questions at the end of this page.

## One screen

Write one block for each screen.

| Line | What to write | Your answer |
| --- | --- | --- |
| **Reference** | A number given once and never reused | |
| **Name** | What the person is doing here, in the words the business uses | |
| **Steps it serves** | The goals it serves, and for each the numbered steps and variations of that goal that this screen shows | |
| **Records shown and records changed** | Two lists, by name | |
| **Entries, rules and quality requirements** | The references, or: none, which is an answer and not an empty line | |
| **For every value: where it comes from** | Typed by the person; chosen from a list, with the list and its owner; read from another record or another body, named; or worked out by a named rule. If it can be got no other way, say why | |
| **For every value: the least and the most** | What the screen demands and what it admits, as two separate decisions | |
| **Which act leads to which other screen** | One line for each | |
| **Status and version** | Draft, reviewed or baselined; and the version | |

## The set of screens as a whole

Write these once.

| Line | What to write | Your answer |
| --- | --- | --- |
| **How the set was worked out** | From which use case, in which version | |
| **Steps and variations reached** | How many there are, which are reached, and the written reason wherever one is not | |
| **Interests of the stakeholders** | One sentence against each, saying whether it is visible to the person on the screen | |
| **What agreeing to the walk-through commits the parties to** | And what it does not | |
| **Who owns the set** | Who may propose a change, and who decides | |
| **Questions genuinely in dispute** | Each with an owner and a date; never closed by a silent default | |

## Before you accept it

1. Does every value on every screen say where it comes from?
2. Is every step of the story shown on some screen, and every screen tied to a step?
3. Does every screen state the least and the most that it demands and admits?
4. Is every interest of the stakeholders visible to the person who needs to see it?
5. Does every question in dispute have an owner and a date?
