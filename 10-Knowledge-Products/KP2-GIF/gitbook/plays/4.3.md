## Example input

Country: Progressa.

Standards already in use: Linkup runs X-Road 7.x (pilot since 2025). The 2021 e-Government Interoperability Framework has an approved-standards list, but no current project applies it.

From the standards-to-reuse shortlist (B7): OneRoster and CEDS for learner and enrolment data; W3C Verifiable Credentials for certificates; ISCED 2011 for education levels; Giga's school data for schools.

From the component-to-layer map (B20): security servers at every member's edge, a Central Server at PDGA, no event layer yet.

**Decisions that need deliberation**

- **OpenAPI 3.0 or 3.1.** Most tools handle both. Pick one, because members who mix them meet small differences in schema rules.
- **OAuth inside the bus, or not.** X-Road already authenticates every calling subsystem by certificate. OAuth adds end-user authorisation. Decide whether a service needs both.
- **OneRoster or CEDS.** They overlap for learners. Choose which one owns each entity.
- **The 2021 list.** Retire it formally, or it stays a second, competing portfolio.

## Reading the output

### 1. The OAuth decision is the right one to raise

The input says the bus authenticates by certificate. The run did not just list OAuth as the menu's default. It asked whether a service needs it as well. The build pack's two contracts carry no OAuth at all: the caller is known by its X-Road subsystem. That is a deliberate choice, and the portfolio should record it as one.

### 2. Every version is a guess until checked

The run printed version numbers and marked them [confirm], as it was told. Some will be right and some will be out of date, and the table looks equally sure of both. The pack's contracts are written in OpenAPI 3.0.3, not 3.1. That alone shows the row has to be checked against what members actually run.

### 3. The sector vocabularies have no row

OneRoster, CEDS, ISCED and the Giga schema came in with the input and ended up only in a decision bullet. The prompt's seven needs are generic, so the education vocabularies fell between rows. Add a row for "sector vocabularies", with an owner, before the portfolio goes to the APIs Working Group.
