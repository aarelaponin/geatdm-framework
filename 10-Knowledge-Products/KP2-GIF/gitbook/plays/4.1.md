## Example input

Country: Progressa. Components, taken from A0 §6 and the Linkup pilot plan:

- the Linkup Central Server, run by PDGA (X-Road 7.x, pilot since 2025);
- one security server each for PDGA (management), PNIA, PLR and PNEA;
- the pilot's test certification authority, with its OCSP responder and timestamping service;
- a service catalogue listing each member's published services (none published today);
- a monitoring dashboard for PDGA's operations staff;
- an identity adapter that puts PNIA's e-KYC platform behind its security server;
- a store for the security servers' message logs.

**Gaps per layer**

- **Service Access:** a developer portal or sandbox where a new member tests a call before go-live.
- **Event Distribution:** nothing at all. No publish–subscribe channel for "learner enrolled" or "birth registered".
- **Trust and Security:** an accredited production CA with identity vetting; a test CA vouches for anyone who asks.
- **Governance and Administration:** a collector that gathers monitoring data from every security server; a published member register.

## Reading the output

### 1. The empty layer is the finding

Event Distribution has no component. That matches the build pack, which runs request and response only. It is a fair choice for a first bus, but only if it is recorded as a deferral with a date. Otherwise it is just a gap nobody noticed.

### 2. The monitoring gap is overstated

The run lists a dashboard as planned and still calls monitoring a gap, and it never says that X-Road ships monitoring add-ons on each security server. The pack has those add-ons installed. What it lacks is a central collector. That is the safeguard in action: check a gap against the software before you budget for it.

### 3. The identity adapter does not belong in the platform list

PNIA's e-KYC adapter is a member's system that sits behind its own security server. It is not a part of the bus. Putting it in the platform inventory blurs who pays for and runs it. Move it to PNIA's member record, and ask the same question of every component the input names.
