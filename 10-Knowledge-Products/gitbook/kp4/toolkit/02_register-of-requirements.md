# The register of requirements

One entry for each separate thing the customer asked for, in the customer's words, with where it was said. The register records what was asked, before anyone designs.

| | |
| --- | --- |
| **Document of the twelve** | 2 |
| **Who writes it** | An AI assistant extracts it; the analyst rules on each entry |
| **What goes in** | Document 1, the customer's own documents |
| **Who accepts it** | The analyst accepts, amends or sets aside each entry |
| **Taught in** | 2.2 |

## How to use this blank instrument

Copy this page into your own document. Fill in the answer to every line. Do not leave a line empty: write "none" where nothing applies, and where the answer is not yet known write an open question with the name of its owner and a date. Do not guess an answer to close a question. When the document is finished, give it to the person who accepts it, together with the questions at the end of this page.

## One entry

Write one entry for each separate thing asked.

| Line | What to write | Your answer |
| --- | --- | --- |
| **Reference** | A number from this register's own series | |
| **Kind** | Function, quality or constraint | |
| **Subject** | The business area the entry belongs to | |
| **What was asked** | The sentence, in the customer's words | |
| **Quoted or paraphrased** | Quoted; or paraphrased, together with the customer's own words | |
| **Where it was said** | The customer's document, the place in it, and the words | |
| **How you would see it done** | One sentence in the language of observation: what a person would see | |
| **Priority** | A value of the register's scale; or: not set | |
| **Set by** | The person or role and the date; or: nobody, not set | |
| **Status** | Proposed, in force, amended, withdrawn or set aside | |
| **If set aside** | Who signed it, the date and the reason | |
| **If amended** | What changed, and against which version | |
| **Open question** | What is unresolved, with an owner and a date | |

## The register as a whole

Write these once.

| Line | What to write | Your answer |
| --- | --- | --- |
| **Order** | What the entries are ordered on, and where that order came from | |
| **Priority scale** | The fixed set of values, defined once | |
| **Counts, stated and not judged** | How many entries; how many have no source; how many have no one who set the priority | |
| **Version, date and status** | As for every document | |

## Before you accept it

1. Is every entry in the customer's words, with the document and the place where it was said?
2. Is anything written as asked that the customer did not say?
3. Does every entry say how a person would see that it was done?
4. Is every entry that was set aside signed, dated and given a reason?
5. Does every open question have an owner and a date?
