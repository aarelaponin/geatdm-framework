# The catalogue of the sector's services

One list of every service the sector's bodies owe, with what each rests on, written once for the whole sector before any one service is specified. It shows which blocks many services share.

| | |
| --- | --- |
| **Who writes it** | The team that commissions the services, for the whole sector |
| **What goes in** | The mandate and the law of the sector, and the list of the bodies that owe services |
| **Who accepts it** | The owner of the catalogue, before any one service is specified |
| **Taught in** | 2.1 |

## How to use this blank instrument

Copy this page into your own document. Fill in the answer to every line. Do not leave a line empty: write "none" where nothing applies, and where the answer is not yet known write an open question with the name of its owner and a date. Do not guess an answer to close a question. When the document is finished, give it to the person who accepts it, together with the questions at the end of this page.

## One row for each service

Write one row for every service. A service is something a body owes to a customer.

| Line | What to write | Your answer |
| --- | --- | --- |
| **Reference** | A number you give once and never use again | |
| **Name** | A verb and its object, from the customer's side, in the sector's words | |
| **What it gives** | One line: the result the name stands for | |
| **Customer** | The one role the service is delivered to | |
| **Owning body** | The one body that owes and delivers it | |
| **Other parties** | Every other party involved, and what each does: supports, stands behind, or takes part from outside | |
| **What obliges it** | The law, regulation or decision that requires it, with its section; or: observed in practice, derived, or searched for | |
| **Registers it reads and changes** | Two lists, in the names of the sector's registers | |
| **What the customer presents, what comes out, how it is delivered** | Three short answers | |
| **How it is delivered today** | From the catalogue's own short list of states; or: not established, with the question that would settle it | |
| **What it rests on** | The shared blocks and the system that delivers it, or none | |
| **Stage** | The stage of the sector's roadmap in which it is delivered digitally; or: not placed | |
| **Status and priority** | Draft, reviewed or baselined; priority set on one scale for the whole catalogue | |

## The catalogue as a whole

Write these once.

| Line | What to write | Your answer |
| --- | --- | --- |
| **Scope** | The sector and the bodies the catalogue covers | |
| **Blocks shared by many services** | For each block, the services that rest on it | |
| **Open questions** | Each with an owner and a date | |

## Before you accept it

1. Is every service one that a body owes to a customer, named from the customer's side?
2. Does every service name the one body that owes it and the law or decision that obliges it?
3. Does the catalogue show which blocks many services share?
4. Is every service whose delivery is not established marked so, with the question that would settle it?
