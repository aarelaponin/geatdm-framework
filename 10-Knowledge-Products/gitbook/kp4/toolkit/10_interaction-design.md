# The interaction design

How officers pick, find, move and act, settled once for the whole application, so that no screen decides it again. A program compares what this document lists with the screens.

## How to use this blank instrument

Copy this page into your own document. Fill in the answer to every line. Do not leave a line empty: write "none" where nothing applies, and where the answer is not yet known write an open question with the name of its owner and a date. Do not guess an answer to close a question. When the document is finished, give it to the person who accepts it, together with the questions at the end of this page.

## How an officer picks

Write one row for each list from which an officer picks a value.

| Line | What to write | Your answer |
| --- | --- | --- |
| **The list** | Its name, as in the shared groundwork; or: not in the model | |
| **Members in force** | How many values the list has now | |
| **Maintained or fixed** | Whether the administration maintains the list, and by which role | |
| **Categories** | No list longer than nine: the categories the officer picks first, or: none, because the list is short | |
| **Code shown as label** | Whether the officer sees the code itself or its label | |

## How an officer finds

Write one row for each place where an officer picks another record.

| Line | What to write | Your answer |
| --- | --- | --- |
| **Where** | The form and the field | |
| **Found by** | A search, or a pick from a short list | |
| **What the choice fills in** | The fields filled from the record picked, or: nothing | |
| **What is then locked** | Which of those fields the officer may not change, or: nothing | |
| **When nothing is found** | What the officer sees | |

## How an officer acts

Write one row for each act that opens a form or carries a record.

| Line | What to write | Your answer |
| --- | --- | --- |
| **Stands on** | The form, list or menu heading it stands on | |

## Before you accept it

1. Is every list longer than nine divided into categories, with the category picked first?
2. Does every move between states name who may make it and the words on its button?
3. Does every place where an officer picks a record say what the choice fills in and what it locks?
4. Were the lists, moves and acts compared with the screens, and was every difference settled?
