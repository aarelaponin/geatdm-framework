# E2.5 — PHEQA's shared groundwork: a setting, a code list and the licence's states

**Subtopic:** 2.5 — What every goal may use, and may not invent

**Public anchor:** None; the content is the SDD method's own: the shared registers of states, settings and code lists

**Simulated case:** This is a simulated case for Progressa, a fictional country; every institution, name, date and figure in it is invented.

**What it shows.** PHEQA's shared groundwork in three parts, a setting with an owner, a shared code list and the licence's states, with a goal's draft that wrote the fee as a figure into its own text and the question it should have raised instead.

**Form of this example.** The three kinds of shared thing are the method's and name no country. The fee, the list and the states are filled for Progressa; the fee is invented.

## Why some things are written once

Several goals need the same things: the fee for an application, the kinds of institution, the states a licence can be in. If each goal writes its own, they will disagree within a year. So they are written once, in one shared document, and every goal reads them from there. A goal that needs something that is not there does not invent it; it raises a question.

## Part 1 — A setting with an owner: the application fee

| Line | Answer |
|---|---|
| Name | The application fee |
| What it is | The amount an applicant pays with an application for a licence |
| Its value | 1,200, in Progressa's currency (invented for these examples) |
| Owner | The finance officer of PHEQA |
| Its source | The fee schedule PHEQA issues under article 7 of the Higher Education Regulations |
| Who reads it | The goal *apply for a provisional licence* (to show the fee due) and the goal *record the application fee* (to check the payment) |
| How it changes | The finance officer records a new value with the date it takes effect. An application already made keeps the fee it was made under. |

## Part 2 — A shared code list: the kinds of institution

| Code | Kind of institution |
|---|---|
| UNI | University |
| UCO | University college |
| TEC | Technical institute |

Issued by PHEQA. The list may grow when PHEQA's classification changes; a kind that is retired stays readable on every record that used it. Every goal that asks for a kind of institution offers this list and no other.

## Part 3 — The licence's states

A licence is always in one of three states.

| State | Meaning | It moves to | Who may move it |
|---|---|---|---|
| Granted | The institution may operate | Suspended; cancelled | The registration officer, recording the minister's decision |
| Suspended | The institution may not admit new students until the suspension ends | Granted; cancelled | The registration officer, recording the minister's decision |
| Cancelled | The institution may no longer operate under this licence | The state it held before, granted or suspended, only if a decision on appeal or on review sets the cancellation aside | The registration officer, recording that decision |

## A goal that invented instead of asking

The first draft of the goal *apply for a provisional licence* contained this step:

> "Step 6. The system shows the fee due, 1,000, and asks the applicant to pay it through the Payments block."

The figure 1,000 appears nowhere in the shared groundwork. The analyst had seen it in an old letter on the registration desk and wrote it into the goal's own text. Had it been built, the self-service would have asked for the wrong fee, and the finance officer would have found the mistake only when payments did not match her schedule. Changing it later would have meant finding every goal that had copied the figure.

The step should have read the setting, and if the setting did not yet exist, it should have raised a question:

> "Step 6. The system shows the fee due, the application fee as the shared groundwork holds it, and asks the applicant to pay it through the Payments block."
>
> "**Question for the shared groundwork:** this goal needs the application fee. Is it a single amount, or does it differ by kind of institution? Owner: the finance officer of PHEQA."

The finance officer answered: one amount for every kind. The setting was written once, with her name on it, and the step reads it.

**What to look for before you accept a goal.** Search the draft for figures, periods and lists of choices. Each one should be read from the shared groundwork, with an owner there. A figure that lives only in the goal's own text is an invention, however reasonable it looks.
