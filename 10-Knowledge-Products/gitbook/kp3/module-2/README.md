# Module 2 — The Registration block

**Written for:** the team that configures the service (Architect register). **Videos:** 6.

**What it teaches.** A registration service set up from a description: the application, the checks, the officer's decision, the write to the register.

**What you can do afterwards.** Set up a registration service from a description, with its checks, its officer's decision and its write to the register.

**What is built.** Configurations R1 to R10

## Subtopics

| # | Subtopic | Class | Demonstration | Single message |
| --- | --- | --- | --- | --- |
| [2.1](2-1.md) | What the Registration block does | Core | — | A registration block takes an application, lets an officer decide and, on approval, writes to a register and gives the applicant proof, and built once it serves every ministry that registers people or things. |
| [2.2](2-2.md) | The published specification, and how to judge a product against it | Supplementary | — | Ask every vendor to show the product against the published specification, requirement by requirement, and check whether GovStack lists it and at which compliance level. |
| [2.3](2-3.md) | Generating the registration service | Core | Yes | Describe your registration in the specification's terms, and an AI assistant drafts the service description that sets the block up, which you then import, test and correct. |
| [2.4](2-4.md) | Checks before the officer decides | Core | Yes | Three kinds of check stop a bad application before it reaches the officer: rules on each field, a comparison with the identity authority's record, and a test of completeness on sending. |
| [2.5](2-5.md) | The officer decides, and the record is written | Core | Yes | A registrar approves, rejects or sends back each application, and only on approval does the block write the record to the register, in a sequence the specifications leave you to define and test. |
| [2.6](2-6.md) | The whole service as a description you can move | Supplementary | Yes | The whole service is a description you can test, publish, export and import elsewhere, so a second ministry starts from yours and not from nothing. |
