# Module 2 — Prepare: set up what the AI knows and can do

**Written for:** the public servant who commissions and accepts AI-assisted work and answers for it: a director, a head of unit, a technical secretary briefing the principal. No programming is assumed.

Module 1 taught one good chat. Module 2 teaches the setup that makes every later chat better: a context written once and reused, a project that carries a team's standing instructions and files, skills that package a procedure and connectors that reach a source, and what must never go into any of them. Each page carries the concept, what to do in the tool, a worked example on Progressa, an AI usage tip with a copy-paste prompt, and its sources.

## Pages

| # | Page | Single message |
| --- | --- | --- |
| [2.1](2-1.md) | Build the context once | Write down once, with dates and sources, what every task needs to know about your country and your unit, and give each task only the part it needs. |
| [2.2](2-2.md) | Projects and standing instructions | Say once, in a project, what you would otherwise paste into every chat: who you are, what you produce, the rules, and the files. |
| [2.3](2-3.md) | Skills and connectors | A skill packages a procedure you repeat; a connector lets the assistant reach a source; choose the lightest setup that does the job. |
| [2.4](2-4.md) | Judgement: what never goes into the setup | A setup is used by every later chat, so nothing confidential goes into it, every file carries a date, and the intent is written down. |

## Go further

When you have run this module's tips, one of these takes you further. The Sources on each page say what a claim rests on; this list is what to do next.

- [AI Fluency: Framework and Foundations](https://academy.claude.com/courses/ai-fluency-framework-foundations) — Anthropic Academy. Delegation, the skill this module sets up: what to hand to an assistant, and how. *About 3 hours.*
- [AI and digital transformation competencies for civil servants](https://unesdoc.unesco.org/ark:/48223/pf0000384963) — UNESCO. The competencies a government expects of staff who set up and govern these tools. *A report to read.*
- [AI Skills Coalition](https://aiforgood.itu.int/ai-skills-coalition/ai-courses-portfolio/) — ITU. ITU's free course catalogue; start with 'AI and digital transformation in government'. *About 12 hours.*
