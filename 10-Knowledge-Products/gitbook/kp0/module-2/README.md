# Module 2 — Prepare: set up what the AI knows and can do

**Written for:** the public servant who commissions and accepts AI-assisted work and answers for it: a director, a head of unit, a technical secretary briefing the principal. No programming is assumed.

Module 1 taught one good chat. Module 2 teaches the setup that makes every later chat better: a context written once and reused, a project that carries a team's standing instructions and files, skills that package a procedure and connections that reach a source, and what must never go into any of them. Each page carries the concept, what to do in the tool, a worked example on Progressa, an AI usage tip with a copy-paste prompt, and its sources.

## Pages

| # | Page | Single message |
| --- | --- | --- |
| [2.1](2-1.md) | Build the context once | Write down once, with dates and sources, what every task needs to know about your country and your unit, and give each task only the part it needs. |

| [2.4](2-4.md) | Judgement: what never goes into the setup | A setup is used by every later chat, so nothing confidential goes into it, every file carries a date, and the intent is written down. |
