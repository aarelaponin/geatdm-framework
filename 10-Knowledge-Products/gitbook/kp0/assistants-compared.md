# Assistants compared

The concept on every page of this course works in any assistant. The half headed In the tool is shown in Claude. This table says where the same settings sit in three other assistants a ministry may have approved. It names what each setting does rather than the exact words of a menu, because menus change. Checked on 26 October 2026; check your own assistant's help pages for the current names.

| Setting | Claude | ChatGPT | Gemini | Microsoft 365 Copilot |
| --- | --- | --- | --- | --- |
| Choosing the model ([1.1](module-1/1-1.md)) | A model menu beside the message box | A model menu at the top of the chat | A model menu beside the message box | Mostly set by the organisation; some plans offer a choice |
| Web search with citations ([1.1](module-1/1-1.md), [1.3](module-1/1-3.md)) | Web search, turned on in the tools menu; claims carry citations | Search, used when needed or asked for; answers carry citations | Answers grounded in Google Search, with a check that marks supported sentences | Web grounding, which an administrator can turn off; answers carry references |
| Instructions for every chat ([2.2](module-2/2-2.md)) | Profile preferences in the settings | Custom instructions in the settings | Instructions saved in the settings | Personalisation in the settings, where the organisation allows it |
| A project with instructions and files ([2.2](module-2/2-2.md)) | Projects | Projects | Gems | Notebooks, with Copilot instructions |
| Packaged procedures ([2.3](module-2/2-3.md)) | Skills, uploaded in the settings | Check the current help pages | Check the current help pages | Agents, built by the organisation |
| Connections to sources ([2.3](module-2/2-3.md)) | Connectors, including custom ones by address (MCP) | Apps and connectors | Apps linked to Google services | The organisation's own files and mail, and connectors an administrator adds |
| Memory and how to clear it ([2.4](module-2/2-4.md)) | Memory in the settings, viewable and editable; incognito chats | Memory in the settings; temporary chats | Saved information and activity in the settings; temporary chats | Memory in the settings, where the organisation allows it |

Two cells say 'check the current help pages': at the date of the check, the vendor's own pages did not settle the point. In an organisation's account, an administrator may have turned any of these settings on or off for everyone.
