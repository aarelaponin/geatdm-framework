# Reviews

This folder holds the reviews of the mini registry, one to each report reviewed, and nothing else. A review judges a report against the tests of success of its instruction and carries the verdict. The name of each file begins with `REVIEW_`.

**Who writes here.** A reviewing session that the owner starts from the review instruction. Never the session that wrote the instruction, and never the session that carried it out.

**What governs it.** The orchestrator procedure, which is the skill `orchestrator` in the plugin `fa-project-ops`, sections 6.3 and 6.4, and the review form beside it, `REVIEW-template.md`.

**When a file is written.** After the report has arrived and the agreement between the instruction and the report has been checked.
