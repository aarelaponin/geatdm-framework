# Reports

This folder holds the reports of the mini registry, one to each instruction carried out, and nothing else. A report is the working session's account of what it did, with its evidence. The name of each file begins with `REPORT_`.

**Who writes here.** The working session that carried out the instruction, and no other.

**What governs it.** The orchestrator procedure, which is the skill `orchestrator` in the plugin `fa-project-ops`, section 6, and the report form beside it, `REPORT-template.md`. A report names the instruction it answers, and the two must agree.

**When a file is written.** At the end of the round, before the round closes its row in the record of what is running. A report carries no verdict: the verdict is the review's.
