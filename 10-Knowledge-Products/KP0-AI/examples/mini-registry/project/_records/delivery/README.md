# What this folder holds

In the mini registry, this folder holds:

- the record of each long delivery, at `_records/delivery/<delivery>.md`; each gets a file of its own, named in place of the words in angle brackets.

This folder was made at the inception of the project, on the owner's ruling of the map. The project's constants, `CONSTANTS.md`, record where each of these lives. A place changes only by a ruling, and files are never moved to follow it.
