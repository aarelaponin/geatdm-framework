# The ledger of orchestrator events

This folder holds the ledger of orchestrator events of Arne Laponin's orchestrators, one file per event.
Every file in it is written by `ledger.py` and by nothing else.
No entry is ever edited or deleted; a correction is a later entry.
The ledger is described in section 9 of the orchestrator procedure, `~/Library/Application Support/Claude/local-agent-mode-sessions/ffbe2f0e-bc4b-46d3-ad76-b08a7882aae9/7bbcb800-2754-4c5e-97ea-ccb874ea3fee/rpm/plugin_018SiGJfFaxxAvevS4xGQJgb/skills/orchestrator/SKILL.md`.
