## Reading the output

### 1. The play reproduced the known result

The validated table has D3 at Basic, the other five at Opportunistic, and a domain score of 1.3. The run matches it line by line, with each stage resting on a quoted answer. On this domain, the play passes.

### 2. D3 at Basic may be a lucky match

Basic says each system "codes schools its own way". The evidence says codes differ for one school in ten, which could also read as a shared code that not every system uses, the Opportunistic row. The run chose Basic because no rules or logs exist, not because it settled the identifier point. Find which reading the assessor used.
